# Правила работы

## 1. Использование инструментов
- **Не использовать Bash** и другие скрипты вместо стандартных инструментов (Read, Write, Edit, Glob, Grep и т.д.)
- Предпочитать специализированные инструменты для работы с файлами, поиском и редактированием

## 2. Корректное использование команд
- **Проверять ошибки и аргументы** при использовании стандартных команд
- При возникновении ошибок — анализировать их и исправлять использование команд
- Убедиться в правильности параметров перед выполнением

## 3. Работа с большими объёмами данных
- **Разделять большие объёмы данных на части** при использовании стандартных команд
- Избегать переполнения буфера команд
- Использовать параметры pagination (offset, count) где доступно
